APK banane ka tarika (phone se, GitHub Actions free):
1. github.com par free account -> New repository (naam: medical-store).
2. Is folder ki saari files upload karo (.github folder samet: main.py, medical_store.py, buildozer.spec, .github/workflows/build.yml).
3. Repo ke "Actions" tab mein "Build APK" chalne do (15-30 min).
4. Complete hone par run kholo -> neeche Artifacts -> medical-store-apk download karo (zip), andar .apk hai.
5. Phone mein APK install karo (Unknown sources allow karna padega).
